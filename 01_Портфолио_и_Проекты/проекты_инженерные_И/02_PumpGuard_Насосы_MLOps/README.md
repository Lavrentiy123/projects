PumpGuard MLOps — это масштабируемая система предиктивного обслуживания (Predictive Maintenance) Enterprise-уровня, спроектированная для мониторинга и прогнозирования отказов крупного парка промышленного оборудования (500+ насосов).


В современной индустрии датчики IoT ежесекундно генерируют терабайты телеметрии (вибрация, температура, давление). Традиционный подход Data Science, заключающийся в загрузке CSV-файлов в оперативную память с помощью Pandas, неизбежно приводит к сбоям Out of Memory (OOM) и абсолютно неприменим в реальных производственных условиях. Данный проект решает проблему обработки сверхбольших объемов данных, перенося фокус с локальных ML-экспериментов на построение распределенных, отказоустойчивых конвейеров (Pipelines).


В основе архитектуры лежат передовые инструменты Data Engineering и MLOps:


Хранение и ETL-процессы (Big Data): Непрерывный поток "сырых" данных от датчиков агрегируется в высокопроизводительной колоночной СУБД ClickHouse. Для извлечения признаков (Feature Engineering) и сжатия временных рядов используется Apache Spark (PySpark), что позволяет обрабатывать гигабайты логов распределенно, не перегружая RAM.


Deep Learning: В качестве математического ядра используется архитектура Time-Series Transformer, написанная на PyTorch. В отличие от устаревших LSTM, механизм Attention позволяет модели эффективно находить сложные долгосрочные зависимости в показателях датчиков и предсказывать выход оборудования из строя за 7-14 дней до критической поломки.


MLOps и Оркестрация: Проект полностью автоматизирован. Apache Airflow управляет жизненным циклом системы с помощью графов задач (DAGs): он по расписанию запускает ночную выгрузку новых данных, инициирует дообучение модели и выполняет инференс (Batch Scoring). Все метрики, гиперпараметры и веса моделей строго версионируются и хранятся в MLflow Model Registry.


Вся инфраструктура проекта (Airflow, Spark-workers, бакенд MLflow и базы данных) разворачивается в изолированной среде с помощью Docker Compose, что гарантирует идеальную воспроизводимость. PumpGuard MLOps демонстрирует полный переход от «ноутбучного ML» к зрелой корпоративной архитектуре.
