# 📦 StockFlow: ИИ-агент прогнозирования спроса и автозакупок

* **Роль:** Системный инженер (Лаврентий Ямпуров в кросс-функциональной команде из 7 человек)
* **Стек:** Python, SQL, Time-Series ML, BPMN 2.0, User Stories, Scrumban, Jira
* **Презентация проекта:** [Google Slides](https://docs.google.com/presentation/d/15nC8xzPXrTYodyBwwZRlJSDey06OYHEKwI0ocs4V1ic/edit?usp=sharing)

## 📌 Зона ответственности Лаврентия:
1. Декомпозиция бизнес-целей заказчиков розничной сети по SMART и User Stories.
2. Проектирование архитектуры в BPMN 2.0, проектирование User Flow веб-интерфейса.
3. Постановка инженерных ТЗ для дата-инженеров (ETL) и дата-сайентистов (ML-модель).
4. Управление рисками качества данных и координация спринтов по Scrumban.

## 🚀 Быстрый запуск
```bash
python run_stockflow_forecast.py
```
Скрипт выполняет расчет автозакупок на 14 дней вперед и выгружает `stockflow_summary.json`.
