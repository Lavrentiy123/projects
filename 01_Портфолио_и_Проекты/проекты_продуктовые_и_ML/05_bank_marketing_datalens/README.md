# 🏦 Bank Marketing Campaign Analytics (Yandex DataLens)

* **Роль:** Бизнес-аналитик / Data Analyst (Лаврентий Ямпуров)
* **Стек:** Yandex DataLens, SQL, Excel, UCI Bank Marketing (41 188 записей)

## 📌 Ключевые аналитические результаты:
1. Интерактивный BI-дашборд с 3 KPI, 5 визуализациями и 3 фильтрами.
2. Общая конверсия кампании: 11.27% (4 639 успешных депозитов).
3. Звонки длительностью 5+ минут увеличивают конверсию в 3 раза (до 34.2%).
4. Самые отзывчивые сегменты: студенты (31.4%) и пенсионеры (25.3%).

## 🚀 Запуск аналитического скрипта
```bash
python run_bank_marketing_analysis.py
```
