## 💡 Описание архитектуры конвейера

Данный проект — полнофункциональный, автономный рабочий прототип целевой мультиагентной системы для Департамента по стратегии, инновациям и устойчивому развитию (ДСИиУР) ПАО «Газпром нефть».

Конвейер устраняет «коммуникационный разрыв» между утвержденной стратегией компании и профильными подразделениями за счет работы 3 сквозных агентов:

```
[Входящий сигнал ТЭК]
         │
         ▼
┌─────────────────────────────────┐
│ 🤖 Агент 1: Аналитик            │ ──► Выделяет угрозу ТЭК, степень риска
│ (Early Warning Signal Card)     │     и затронутые дочерние общества (Хантос, Заполярье)
└─────────────────────────────────┘
         │ (Pydantic v2: ThreatSignal)
         ▼
┌─────────────────────────────────┐
│ 🤖 Агент 2: Стратег             │ ──► Синтезирует проект импортозамещения
│ + Нода-Критик (Reflexion Loop)  │     Итерация 1: 6.85/10 (ОТКЛОНЕНО: риск санкций)
└─────────────────────────────────┘     Итерация 2: 9.19/10 (ОДОБРЕНО ИНВЕСТКОМИТЕТОМ)
         │ (Pydantic v2: StrategicInitiative)
         ▼
┌─────────────────────────────────┐
│ 🤖 Агент 3: Презентатор         │ ──► Каскадирует на диалекты блоков:
│ (Каскадирование и Авто-верстка) │     • Бурение и ВСР (проходка м/ст-мес, MWD)
└─────────────────────────────────┘     • Логистика и флот (СМП, фрахт, Сабетта)
         │                              • Дирекция ИТ (Astra Linux, КИИ, SCADA)
         ▼
┌─────────────────────────────────────────────────────────────────┐
│ 📦 Выходные артефакты:                                          │
│ 1. gazprom_executive_deck.pptx (6 слайдов 16:9 по брендбуку)    │
│ 2. gazprom_strategy_digest.docx (Аналитический дайджест в Word) │
│ 3. pipeline_output.json (Сквозной машиночитаемый лог)           │
└─────────────────────────────────────────────────────────────────┘
```

## 📂 Структура файлов в папке `03_gazprom_agent_prototype`

| Файл | Назначение |
| :--- | :--- |
| `run.py` | Главный исполняемый модуль конвейера: содержит схемы Pydantic v2, функции 3 агентов (`agent_1_analyst`, `agent_2_strategist`, `agent_3_presenter`), алгоритм скоринга, контур Reflexion и движки генерации PPTX и DOCX. |
| `gazprom_executive_deck.pptx` | Итоговая 6-слайдовая презентация 16:9 в стандартах брендбука «Газпром нефти» (`#0072CE`, карточный дизайн, визуализация скоринга и KPI). |
| `gazprom_strategy_digest.docx` | Официальный аналитический дайджест в формате Microsoft Word для экспресс-ознакомления руководства. |
| `pipeline_output.json` | Машиночитаемый лог конвейера для интеграции в корпоративные BI/ERP. |
| `README.md` | Данная техническая документация. |
