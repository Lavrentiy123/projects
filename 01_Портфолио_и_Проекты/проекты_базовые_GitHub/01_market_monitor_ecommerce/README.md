# 🛒 Проект 1: Мониторинг рынка и цен конкурентов (E-commerce Retail)

**Направление:** Косвенный проект в портфолио (демонстрация навыков анализа потоковых данных и детекции сигналов)  
**Стек:** Python 3.9+, Pydantic v2, HTML5/CSS3, JSON Schema  
**Разработчик:** Лаврентий Ямпуров  

---

## 💡 Описание
Автоматизированный сервис мониторинга цен, складских остатков и пользовательских отзывов конкурентов в сегменте розничной торговли / маркетплейсов. 
Система выявляет аномалии трех типов:
1. **Демпинг цен** (скидки конкурентов >20%) — формирует контр-предложения по промокодам.
2. **Дефицит у конкурента** (out of stock) — сигнализирует о возможности перехвата органического трафика.
3. **Рост брака / негатива** — формирует тезисы для маркетинговых кампаний о качестве нашего продукта.

---

## 🚀 Запуск
```bash
python run.py
```

## 📦 Артефакты работы

- `competitor_dashboard.html` — адаптивный веб-дашборд со сводной аналитикой и рекомендациями для категорийных менеджеров.
