# 🛒 Мониторинг рынка и цен конкурентов (E-commerce Market Intelligence)

**Направление:** E-Commerce Market Intelligence • Детекция ценовых аномалий и сценарный анализ  
**Стек:** Python 3.9+, Pydantic v2, HTML5/CSS3, JSON Schema  
**Разработчик:** Лаврентий Ямпуров  

---

## 💡 Описание системы
Автоматизированный сервис потокового мониторинга цен, складских остатков и пользовательских отзывов конкурентов в сегменте розничной торговли и маркетплейсов. 

Система выявляет аномалии трех типов:
1. **Демпинг цен** (скидки конкурентов >20%) — формирует контр-предложения и расчет порога маржинальности.
2. **Дефицит у конкурента** (out of stock) — сигнализирует о возможности перехвата органического спроса.
3. **Рост негатива / брака у конкурента** — генерирует целевые тезисы для рекламных кампаний о надежности нашего продукта.

## 📦 Артефакты работы
- `competitor_analysis.json` — строгий контракт данных по схеме Pydantic v2 с анализом 4 конкурентов.
- `competitor_dashboard.html` — адаптивный веб-дашборд со сводной аналитикой и рекомендациями для категорийных менеджеров.
