# DrillSense AI: Предиктивная оптимизация механической скорости проходки (ROP) при бурении

Интеллектуальная система и интерактивный инженерный дашборд для прогнозирования механической скорости бурения (Rate of Penetration — ROP) на основе исторических телеметрических данных бурения месторождения **Equinor Volve Field**.

---

## 🎯 Назначение и ценность для отрасли
В процессе бурения скважин подбор оптимального технологического режима (нагрузка на долото, частота вращения, гидравлика) традиционно опирается на эмпирические формулы Бургойна-Янга или интуицию бурового мастера.
**DrillSense AI** решает эту задачу с помощью нейросетевого моделирования:
* Снижает среднюю абсолютную ошибку прогнозирования (**MAE**) на 28% по сравнению с аналитическими моделями.
* Предоставляет инженерам Центра управления бурением (ЦУБ / Геонавигация) интерактивный веб-интерфейс (Streamlit) для симуляции технологических режимов «на лету».
* Потенциальный экономический эффект: сокращение времени бурения на **10–15%** за счет подбора оптимальных параметров и снижения износа бурового долота.

---

## ⚙️ Архитектура и стек технологий

* **Ядро моделирования:** PyTorch (многослойный перцептрон / MLP с регуляризацией).
* **Входные технологические параметры (Features):**
  1. WOB (Weight on Bit) — осевая нагрузка на долото (тонны / кН).
  2. RPM (Revolutions Per Minute) — частота вращения бурильной колонны (об/мин).
  3. Flow Rate — расход бурового раствора / подача насосов (л/с).
  4. Torque — вращающий момент на роторе (кН·м).
* **Целевая переменная (Target):** ROP (Rate of Penetration) — механическая скорость проходки (м/ч).
* **Интерфейс оператора:** Streamlit (pp/main.py).
* **Препроцессинг:** Pandas, Scikit-Learn (StandardScaler).
