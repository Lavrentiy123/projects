# ⚖️ Экспресс-аудит коммерческих договоров (B2B Legal & Finance Risk Scoring)

**Направление:** LegalTech & Financial Risk Modeling • Контур риск-аудита и генерации протоколов  
**Стек:** Python 3.9+, Pydantic v2, Decision Engine, Markdown  
**Разработчик:** Лаврентий Ямпуров  

---

## 💡 Описание системы
Интеллектуальный аудитор коммерческих договоров и спецификаций поставки на базе критериальной матрицы рисков.
Система решает задачу снижения правовых и финансовых рисков компании при заключении сделок:
1. **Проверка Red Flags:** Отсекает кабальные условия (отсрочка платежа >90 дней, завышенная односторонняя пеня >0.1%/день, отсутствие статьи форс-мажора).
2. **Индекс безопасности (0-100):** Расчет скоринга по штрафной шкале.
3. **Генерация протокола разногласий:** Для рискованных договоров автоматически формирует готовые юридически выверенные пункты правок.

## 📦 Артефакты работы
- `contract_audit.json` — машиночитаемый протокол скоринга с детализацией штрафных баллов.
- `protocol_of_disagreements.md` — официальный протокол разногласий для отправки контрагенту.
