## 🎯 Продуктовая задача
Разработать и развернуть прототип интеллектуального сервиса «Персональный ассистент по здоровью» с веб-интерфейсом, способного вести естественный диалог, помогать пользователю в вопросах здорового образа жизни, организации приема медикаментов и базовой оценке самочувствия при строгом соблюдении медицинской этики и требований безопасности.

---

## 🛠️ Что было сделано:
1. **Формулировка гипотез и сценариев использования:**
   - Разработка базовых пользовательских сценариев: консультации по питанию и ЗОЖ, планирование графика приема препаратов, анализ общих симптомов с маршрутизацией к специалистам.
2. **Проектирование системной архитектуры:**
   - Поток данных от веб-интерфейса через бэкенд к OpenAI API (ChatGPT mini).
   - Поддержка интерактивных команд: `/start` (онбординг), `/help` (справочник возможностей), `/profile` (управление персональным контекстом пользователя).
3. **Обеспечение безопасности и медицинский этический контур:**
   - **Медицинский дисклеймер:** жесткое правило обязательного предупреждения пользователя о том, что ассистент не заменяет квалифицированную врачебную помощь.
   - **Safety Guardrails:** фильтрация и блокировка потенциально опасных запросов (самолечение рецептурными препаратами, критические состояния, требующие экстренной помощи 112).
4. **Тестирование и оптимизация:**
   - Проведение системного тестирования диалоговых веток, проверка устойчивости к некорректным входным данным.
   - Подготовка финального аналитического отчета и видеозаписи работы прототипа.

## 🏆 Результаты и перспективы
* Полностью рабочий интерактивный прототип, развернутый на облачной инфраструктуре Replit.
* Гарантированное срабатывание этических фильтров безопасности и вывод дисклеймеров.
* Сформированный roadmap развития: интеграция с базой знаний доказательной медицины, расширенная система напоминаний о приеме лекарств и push-уведомления.

## 🚀 Воспроизведение и запуск
```bash
python run_health_assistant.py
```
Скрипт выполняет проверку диалоговых сценариев, тестирует защитные фильтры при попытке опасного запроса и сохраняет лог сессии в `health_assistant_log.json`.
