## 📌 О проекте и продуктовой концепции

StockFlow — интеллектуальная система автономного планирования запасов и автозаказа для сетевого ритейла (FMCG). Система решает ключевую дилемму ритейла: минимизация дефицита товаров на полках (**Out-of-Stock**) при одновременном снижении замороженного оборотного капитала и списаний скоропортящейся продукции (**Overstock**).

### Структура презентации проекта (14 слайдов):
1. **Титул:** StockFlow — ИИ-агент прогнозирования спроса и управления запасами.
2. **Проблематика ритейла 2026:** Волатильность цепочек поставок, потери до 4-7% оборота из-за дефицита полок.
3. **Цели по SMART:** Горизонт прогнозирования 14 дней, автоматизация до 60% рутинных заявок, снижение Out-of-Stock на 15%.
4. **Команда проекта:** 7 специалистов (Product Manager, Системный инженер, Data Engineer, ML Engineer, Backend, Frontend, QA).
5. **Функциональные области и KPI:** Метрики точности модели (MAPE < 25%), SLA интеграции с 1C/WMS.
6. **Техническое задание:** Требования к ETL-пайплайну, форматам обмена, обработке промо-акций и праздников.
7. **Матрица рисков:** Риски задержки поставок, аномалий спроса, деградации качества данных.
8. **Методология разработки:** Гибридный фреймворк Scrumban, двухнедельные спринты, трекинг в Jira.
9. **Unit-экономика:** LTV/CAC, окупаемость внедрения ИИ-агента для торговой сети.
10. **Конверсия и воронка внедрения:** Пилотирование в тестовых магазинах, масштабирование на сеть.
11. **Этапы реализации:** От первичной очистки данных до закрытого бета-теста.
12. **Диаграмма Ганта:** График выполнения работ по спринтам и майлстоунам.
13-14. **Сессия Q&A и контакты.**

## 🚀 Воспроизводимый модуль расчета потребностей

В репозитории содержится исполняемый алгоритм расчета оптимального объема заказа (EOQ + Safety Stock):
```bash
python run_stockflow_forecast.py
```
Скрипт симулирует динамику остатков и спроса для ключевых категорий, рассчитывает дефицит с учетом страхового запаса (Safety Stock) и времени плеча поставки (Lead Time), после чего выгружает `stockflow_summary.json`.
