## 🔍 Обоснование и позиционирование для собеседований

### 1. `01_MCP_Сервер_Нефтегаз_RAG`
* **Вопрос интервьюера:** *«Какие документы загружены в векторную базу Qdrant? Есть ли там внутренняя документация компаний?»*
* **Ответ кандидата:** 
  > *«В базе находятся исключительно **официальные открытые стандарты**, опубликованные в свободном доступе: ГОСТ Р 53711-2009 (Правила разработки нефтяных месторождений), СТО по проектированию промысловых объектов и Федеральные нормы и правила Ростехнадзора (ФНП № 534 по предупреждению ГНВП). Внутренние ДСП-документы не использовались. Проект реализовывался совместно со специалистами из технологических компаний: моей задачей было проектирование архитектуры по стандарту Anthropic Model Context Protocol (FastMCP) на Python 3.13, чтобы показать, как корпоративные LLM-агенты безопасно подключаются к векторным базам знаний через стандартизированный протокол stdio и JSON-RPC»*.

### 2. `02_Мультиагентная_Система_Judge`
* **Вопрос интервьюера:** *«Что проверяет этот мультиагентный конвейер? Это код реальных систем?»*
* **Ответ кандидата:** 
  > *«Это архитектурный прототип контура самокритики (Reflexion Loop). В качестве задач используются синтетические инженерные модули (расчет забойного давления и технологических режимов). Ключевая ценность проекта — практическая реализация паттерна **Evaluator-Optimizer + Model Diversity + LLM-as-a-Judge** из методологии Anthropic 'Building Effective Agents': первый агент декомпозирует задачу, второй генерирует решение, третий находит дефекты, а четвертый (независимая модель-судья) выносит скоринг и отправляет на итеративную доработку. Это фундаментальный архитектурный паттерн, гарантирующий исключение галлюцинаций в корпоративных системах»*.
